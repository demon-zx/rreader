### дизайн нового механизма синхронизации позиции чтения

- на устройстве в хранилище помещается уникальный идентификатор - deviceUuid
- при открытии книги шлём deviceUuid и размер экрана
- на сервере проверяем открывалясь книга для этого устройства и размера экрана, если нет то вызываем метод "открыть" рендера
- метод "открыть" делает разметку страниц, какой текст и в какой месте файла находится текст страницы, для страницных форматов типа pdf это будет просто номер страницы
- собираем позиции страниц (позиционный индекс) и отсылаем обратно вместе с автором, кол-вом страниц и прочим
- далее устройство подтягивает позицию по ней и по индексу определяет страницу (pageN <= position < pageN+1), которую отрисовывает
- при перелистывании, по индексу и странице определяется позиция и отсылается на сервер
  
## Сборка

docker build -t ghcr.io/demon-zx/rreader:latest .
docker push ghcr.io/demon-zx/rreader:latest

## Запуск

sudo docker run -d --name rreader -p 7070:8080 --volume /opt/rreader/config:/config --volume /opt/rreader/books:/books -e GID=$(id -g tomcat) -e UID=$(id -u tomcat) --restart=unless-stopped ghcr.io/demon-zx/rreader:latest
