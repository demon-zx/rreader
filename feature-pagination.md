# Функционал «Пагинация» (библиотека)

Постраничный вывод списка книг на странице библиотеки: сервер отдаёт одну
страницу вместе с общим количеством книг и числом страниц, клиент рисует
пагинатор и запрашивает выбранную страницу. Пагинация работает вместе с
поиском; текущие страница и поисковый запрос сохраняются в адресе страницы,
поэтому возврат из книги («Библиотека» → назад) открывает тот же список.

## Готово

### 1. Backend

- [x] `BookService.findAll(q, page, pageSize)` — валидация аргументов:
      `page >= 0`, `1 <= pageSize <= MAX_PAGE_SIZE` (100); при нарушении
      выбрасывается `InvalidArgumentException` ⇒ HTTP 400.
- [x] `AbstractPageMapper` — в `Page.all` записывается общее количество
      записей (`getTotalElements`), а не количество элементов на странице.
- [x] `LibraryController.findBooks` — параметры `page` (по умолчанию 0) и
      `pageSize` (по умолчанию 10) стали необязательными; ошибки сервиса
      обрабатываются через `run(...)` (400/500).

Ответ `GET /api/v1/library?q=&page=&pageSize=`:

```json
{
  "items": [ ... ],
  "all": 57,
  "allPages": 6
}
```

### 2. Frontend

- [x] `library.html` — два одинаковых блока `.pager`: сразу после строки
      поиска и после списка книг; в каждом информация «1–10 из 57» и список
      страниц (Bootstrap pagination).
- [x] `library.js`:
      - номер текущей страницы хранится в `page` (с нуля), размер страницы —
        `PAGE_SIZE = 10`;
      - `renderPager()` рисует оба пагинатора: «предыдущая/следующая», первую,
        последнюю и соседние с текущей страницы, остальные сворачиваются в
        многоточие;
      - пагинаторы скрываются, если страница одна;
      - смена страницы перезагружает список и прокручивает его к началу;
      - поиск и очистка поиска сбрасывают страницу на первую;
      - если после удаления книг текущая страница стала последней + 1,
        автоматически открывается последняя существующая;
      - защита от гонки запросов при быстром вводе (`loadSeq`);
      - состояние (`q`, `page`, 1-based) пишется в URL через
        `history.replaceState`, читается при загрузке;
      - пустой результат показывает «Книги не найдены».
- [x] `library.css` — пагинатор переносится по строкам и прижат вправо.
